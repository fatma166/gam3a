# Taqdeem University Platform UI

واجهة Next.js عربية لمنصة تقديم جامعات، مبنية بناء على تحليل ملف المتطلبات المرفق، مع روح بصرية قريبة من موقع CE Education: واجهة نظيفة، مساحات واضحة، بطاقات معلومات، ونبرة مؤسسية تعليمية.

## الصفحات

- `/` الصفحة الرئيسية للمنصة
- `/universities` دليل الجامعات
- `/universities/[slug]` صفحة تفاصيل جامعة
- `/programs` البرامج والتخصصات
- `/calculators` حاسبات الشهادات
- `/apply` بداية طلب التقديم
- `/dashboard` بوابة الطالب
- `/admin` لوحة تشغيل القبول

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

## ملاحظات التصميم

- الواجهة RTL بالكامل.
- الألوان الأساسية مستوحاة من التحليل: أزرق عميق، تركواز، وذهبي مساعد.
- التصميم يبرز أن المشروع منصة Admissions System، وليس موقع محتوى فقط.
- صفحات الـ Portal والـ Admin تصميمية حالياً وجاهزة للربط لاحقاً مع Laravel API أو أي Backend.
